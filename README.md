# 深蹲40下｜iPhone 網頁 App（PWA）

這是一個可加入 iPhone 主畫面的 PWA 版本。

## 使用
1. 將整個資料夾放到 HTTPS 網站空間（GitHub Pages、Cloudflare Pages、Netlify 等）。
2. 用 iPhone Safari 開啟網址。
3. 點「分享」→「加入主畫面」。
4. 桌面會出現「深蹲40下」。

功能：
- 每日目標（預設 40 下）
- +1 / +5
- 開始深蹲模式
- 本機紀錄
- 連續天數
- 累積統計
- 達標率
- 每日提醒時間設定與通知權限

注意：瀏覽器/PWA 的背景通知受 iOS 限制，不能把「每日定時提醒」保證成為像原生 App 一樣的本地排程通知。若要穩定定時提醒，後續可改成原生 iOS App + 本地通知。
